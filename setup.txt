КОМАНДЫ И ЗАПУСК (Техническая часть)

Если вы скачали проект, но не знаете, как его запустить — эта инструкция для вас.
Важно: Все команды нужно вводить в терминале (командной строке), находясь в корневой папке проекта (там, где лежит файл package.json, и папки backend и frontend).
1. Как открыть терминал в нужной папке

Windows:

    Откройте папку ai-studio в Проводнике.

    Нажмите на адресную строку сверху (где путь к папке).

    Напишите cmd и нажмите Enter.
    (Откроется черное окно, где путь уже будет вести в вашу папку).

Или через VS Code:

    Откройте папку ai-studio в VS Code.

    Нажмите Ctrl + ~ (тильда, буква Ё).
    (Терминал откроется внизу, и путь уже будет правильным).

2. Первичная установка (Делается один раз)

Если вы только что скачали проект, вам нужно установить зависимости и скачать модель.

Команда:

npm run setup

Что она делает:

    Проверяет, установлен ли Node.js.

    Устанавливает все библиотеки для бэкенда и фронтенда.

    Скачивает модель Qwen (если её нет).

3. Запуск проекта (Основная команда)

Когда всё установлено, вы запускаете сам сайт.

Команда:

npm start

Что она делает:

    Запускает Бэкенд (сервер на порту 3000).

    Запускает Фронтенд (сайт на порту 5173).

    Выводит в терминал синие и розовые строчки логов.

    Как зайти: Откройте браузер и введите http://localhost:5173.

(Если вы заходите с планшета или другого ПК по Wi-Fi, используйте IP-адрес вашего компьютера, например http://192.168.0.13:5173).
4. Перезапуск (Если что-то зависло)

Если вы изменили код, или сервер завис, используйте эту команду.

Команда:

npm run reboot

Что она делает:

    Жестко убивает все старые процессы Node.js.

    Запускает бэкенд и фронтенд заново.
    (Это та же команда, что npm start, но с принудительной очисткой).

5. Остановка всех процессов (Аварийная)

Если порты заняты, или терминал не реагирует.

Команда:

npm run kill

Что она делает:

    Принудительно завершает все процессы node.exe на компьютере.

    Освобождает порты 3000 и 5173.
    (После неё нужно снова запустить npm start).

6. Как это устроено (Архитектура)

Для тех, кому интересно, что происходит под капотом.

    Frontend (/frontend) — Это React + Vite. Он отвечает за интерфейс (кнопки, чаты, дизайн). Общается с бэкендом через HTTP-запросы (fetch).

    Backend (/backend) — Это Fastify (Node.js). Он принимает запросы от фронтенда, общается с Ollama (нейросетью), хранит историю в SQLite и отдает ответы обратно.

    Ollama — Локальный движок для нейросетей. Запускается отдельно (или через наш сайт). Он и генерирует текст.

    SQLite (backend/data.db) — Локальная база данных. Там хранятся все ваши чаты и сообщения. Если удалить этот файл — история чатов очистится.

    hidden.json — Файл, где хранятся ID скрытых (удаленных) чатов.

7. Если нужно изменить порт

По умолчанию:

    Бэкенд: 3000

    Фронтенд: 5173

Если эти порты заняты другой программой, их можно поменять:

    Бэкенд: В файле backend/src/server.ts найдите строчку port: 3000 и поменяйте на другой.

    Фронтенд: В файле frontend/vite.config.ts найдите port: 5173 и поменяйте.
    (После этого не забудьте поменять URL в App.tsx, где мы стучимся к бэкенду).
